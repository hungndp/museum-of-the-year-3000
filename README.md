One museum label, at most 200 characters — the label a museum in the year 3000 puts beside an ordinary object from today — entered in the [Museum of the Year 3000](https://make.fun/bounty/u-donrulezz-museum-of-the-year-3000-b727a0bb) bounty on [make.fun](https://make.fun).

## The label

> Charging cable, c. 2024. A leash, kept by the bed, with which humans tethered their pocket oracles overnight so they could not escape.

134 characters. One object, one confident year-3000 misreading: the cable was a leash and the phone a pocket oracle that had to be tethered overnight so it could not escape. The twist word lands last.

## How it works

`main.py` writes exactly that one line to `/output/entry.txt`, with no trailing newline, so the file's byte count is the line's character count. It validates the 1–200 character gate before writing.
